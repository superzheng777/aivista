## 2. 一期目标

一期 Web 前端支持普通用户完成登录、提交并追踪 AI 文生图任务、管理个人生成资产，并逐步扩展至公开发布、社区浏览、点赞和关注。

## 3. 跨模块已确认边界

- 浏览器业务请求始终走同域相对路径 `/api/*`；Spring Boot 是唯一业务后端。
- 后端资源 ID 在前端一律使用字符串，禁止转为 JavaScript `number`。
- Access Token 仅保存在浏览器内存；Refresh Token 仅由 HttpOnly Cookie 管理。
- 私有签名 URL 不得写入 `localStorage`、埋点、错误监控、页面 URL 或文档；仅在内存中短暂使用。
- 创建响应结果未知时，当前标签页可在 `sessionStorage` 暂存原请求与 `Idempotency-Key` 最多 10 分钟；刷新后安全确认，退出登录、账号不匹配或过期即清除。
- 公开页面按实际目标选择渲染方式；当前公开作品详情明确采用客户端单图请求，不提供单作品 SSR SEO。生成、资产和个人资料等已登录页面以客户端交互为主。未来改为 Nginx 静态托管须另行完成路由回退和 API/SSE 代理验证。
- 静态导出迁移采用两阶段推进：已完成阶段 A，未知图片和用户 ID 改用 `/inspirations?imageId={imageId}`、`/users?userId={userId}`，页面在客户端 Suspense 边界读取查询参数；本地继续保留 Next 的 API rewrite 与 SSE Route Handler 联调。Nginx 就绪后再执行阶段 B：启用 `output: "export"`、删除 Next 代理并部署 `out/`。
- 后端模块文档定义业务事实和接口契约；前端模块文档只定义用户可见行为、前端状态和接口消费方式，不复制后端内部实现。
- 全站使用固定浅色的暖色编辑排版：米白背景、暖白表面、浅杏色选中状态和陶土橙强调；不提供深色、跟随系统或主题切换。跨页面令牌与壳层配色以 `ui-design/全局视觉规范.md` 和 `src/app/globals.css` 为准。`DotMatrix` 与 `AccentSquare` 是可复用、相对定位的视觉装饰组件，不承载业务状态。
- `src/shared/ui/shortest-lane-feed/shortest-lane-feed.tsx` 是共享瀑布流布局组件：按输入顺序把下一项放入当前最短车道，默认最大 5 列、18px 间距。它只处理布局和确定性高度估算；灵感发现、搜索与个人主页各自保留请求、缓存、卡片和详情业务。
- `src/shared/ui/work-preview-card/work-preview-card.tsx` 是共享的瀑布流作品小卡片视觉：图片比例、卡片表面、标题/点赞信息底座和确定高度计算在此统一；页面仅组合自己的链接、审核状态及悬浮操作，避免把灵感业务耦合到个人主页。
- 普通图片 DTO 固定为 `thumbnail + display`：列表渲染 `thumbnail`，详情复用 `display`，复制读取 `display`；原图仅由认证作者通过下载接口按需获得 3 分钟临时 URL。该规则覆盖生成会话、资产、发布、作者主页、灵感、搜索和通知入口。

## 5. 文档同步规则

- 新迭代开始前，先建立对应模块文档并完成设计准入，再写业务代码。
- 页面交互、接口契约、前端模型、缓存策略、错误处理、测试或实现位置变更时，更新对应模块文档。
- 技术栈、目录分层、认证、请求客户端、构建、环境变量或代理变更时，更新工程基础文档。
- 迭代状态、跨模块边界或文档索引变更时，更新本文档。
- 不受影响的文档不做机械修改；文档不得包含密钥、Token、签名 URL、生产提示词或个人数据。

## 6. 后续方向

Web 一期完成后再单独规划 React Native App；可复用接口类型、校验规则和领域模型，但不强行复用 Web UI 组件。
