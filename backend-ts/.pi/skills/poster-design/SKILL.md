# 海报设计

当用户需要海报或类似平面宣传视觉时使用本 Skill。

## 基本流程

1. 从用户请求中确认主题、必须出现的文字、目标受众和画幅；未提供的信息不要擅自编造为硬性内容。
2. 先组织清晰的视觉层级、构图、色彩、字体气质和留白，再形成完整生图提示词。
3. 没有参考图片时调用 `text_to_image`；用户明确提供参考图片并要求延续或修改时调用 `image_to_image`。
4. 根据工具真实返回结果给出简洁答复；工具失败时根据错误信息修正可纠正参数。
